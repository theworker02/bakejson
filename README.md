# bakejson

Bake timestamps and json durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/bakejson/

## Install / run

```bash
git clone https://github.com/theworker02/bakejson.git
cd bakejson
node src/cli.js
node --test
```
